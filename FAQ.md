# IBKR Portfolio Analyzer FAQ

## Can it execute trades?

No. Its broker adapter is read-only; draft plans are never submitted.

## Can I try it without an IBKR account?

Yes. The fixture report uses the mock broker adapter.

## Where is my data stored?

The desktop design uses a local database. Optional AI and market-data integrations can contact external providers; review their data flows before enabling them.

## Where are the installers?

Check Releases. No public signed installer is currently confirmed; source build and signing instructions are documented.
