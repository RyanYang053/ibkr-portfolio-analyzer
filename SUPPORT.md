# Support

Start with the [README](README.md), [FAQ](FAQ.md), [engineering reference](ENGINEERING.md) and [current CI](https://github.com/RyanYang053/ibkr-portfolio-analyzer/actions).

Source development and desktop build workflows exist. Supported installer claims require passing platform and signing gates; check Releases and Actions.

For a reproducible issue, include the commit, operating system, runtime version, command and redacted output. Use the repository's issue templates. For vulnerabilities use [SECURITY.md](SECURITY.md). Never share tokens, real statements, account identifiers or private databases. No guaranteed support SLA or financial advice is offered.
