# Code of conduct

This project welcomes contributions from people with different backgrounds and levels of experience. Discuss evidence, design and code respectfully. Disagreement is welcome; harassment, threats, discriminatory remarks, unsolicited disclosure of private information and deliberate disruption are not.

Maintainers may remove inappropriate content, restrict participation or close discussions when necessary. Report a concern privately through the repository's available private reporting channel or request a private contact without posting sensitive details. Never publish brokerage information, credentials or personal data in a report.

For security vulnerabilities, follow SECURITY.md. These guidelines apply to project-managed issues, pull requests and other project spaces.
