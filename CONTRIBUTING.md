# Contributing to IBKR Portfolio Analyzer

Bug reports, focused pull requests, documentation and reproducible examples are welcome.

Search existing issues, fork the repository, create a focused branch, and follow the README setup. Run `cd ai-portfolio-intelligence/apps/api && python -m pytest tests -q` and the demo; include commands and actual results. Use synthetic data, never real statements, account identifiers, credentials or private databases. Preserve read-only, policy and approval controls. Discuss new dependencies and data rights before integration.

First contributions: test installation on a clean environment, improve a synthetic fixture, add an edge-case regression, or improve a confusing output. See SECURITY.md for private vulnerability reports.
